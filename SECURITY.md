# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues
or Discussions.

Instead, report them privately using one of the following channels:

- **GitHub Private Vulnerability Reporting**: go to the
  [Security tab](../../security/advisories/new) of this repository and click
  "Report a vulnerability". This is the preferred method.
- **Email**: [jneto@jnweb.pt](mailto:jneto@jnweb.pt)

Please include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce it, or a proof of concept
- Affected version(s) or commit(s)

## What to Expect

- You will receive an acknowledgement as soon as reasonably possible.
- We will investigate and keep you updated on progress toward a fix.
- Once a fix is available, we will coordinate disclosure timing with you and
  credit you in the release notes, unless you prefer to remain anonymous.

## Supported Versions

Archivum does not yet have tagged releases. Until a first stable release is
published, security fixes are applied to the `main` branch only.
